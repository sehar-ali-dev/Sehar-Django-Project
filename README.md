# MindCare – Psychology Appointment & Assessment System

MindCare is a Django-based psychology appointment and assessment management system designed to support the digital management of psychological services.

## Project Objective

The goal of MindCare is to provide a structured platform where patients, psychologists, and administrators can manage psychological services efficiently.
